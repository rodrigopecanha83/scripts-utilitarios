# Renomear-Fotos-Base-Diretorio-Atual

Utilitário para renomear automaticamente imagens de um diretório utilizando o nome da pasta atual como prefixo sequencial.

## Funcionalidades Principais

* **Prefixo com Nome da Pasta:** Utiliza o nome do diretório atual como identificador padronizado para as fotos.
* **Numeração Sequencial Automática:** Identifica os arquivos de imagem suportados e aplica numeração ordenada.
* **Integração com Menu de Contexto:** Arquivo `.reg` incluso para adicionar o comando diretamente ao botão direito do Windows Explorer.

## Pré-requisitos

* Sistema Operacional: Windows.
* Executável `Renomear-Fotos-Base-Diretorio-Atual.exe`.

## Instalação e Configuração

1. Clone ou baixe este repositório para o seu computador.
2. (Opcional) Para registrar no menu de contexto do Windows Explorer:
   - Copie a pasta com o executável e o ícone para `C:\MenuContexto\Renomear-Fotos-Base-Diretorio-Atual\`.
   - Execute o arquivo `Renomear-Fotos-Base-Diretorio-Atual.reg`.

## Como Usar

Execute o programa via linha de comando ou pelo menu de contexto:

```bash
# Execução direta dentro da pasta das fotos
.\Renomear-Fotos-Base-Diretorio-Atual.exe

# Ou informando o caminho da pasta como argumento
.\Renomear-Fotos-Base-Diretorio-Atual.exe "C:\Caminho\Para\Fotos"
```
